# Expresiones españolas B2–C1

Sitio web interactivo para practicar expresiones coloquiales españolas.

## Publicar con GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube el archivo `index.html` a la raíz del repositorio.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda los cambios y espera a que GitHub publique el sitio.

No necesita instalaciones ni dependencias.
